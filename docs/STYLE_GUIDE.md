# Wing Chun Master Lo Official English Style Guide v1.0

本文件為「盧文錦師父授課精華」網站、YouTube、AI 助理與未來教材使用的英文命名標準。

## 1. 核心原則

- 對外顯示一律使用 `official_en`。
- 其他常見拼法只放在 `aliases`，供搜尋與 AI 辨識使用。
- 不在網站畫面中混用多種拼法。
- 中途若要更改術語，只修改 `data/terminology.json` 的 `official_en`。

## 2. 官方拼法

請使用：

- Chi Sau，不使用 Chi Sao
- Siu Nim Tau，不使用 Siu Lim Tao
- Chum Kiu
- Biu Tze，不使用 Bil Jee
- Muk Yan Chong
- Luk Dim Boon Kwun
- Bart Cham Dao

## 3. 影片標題風格

- Episode 標題使用簡潔、清楚、正式的英文。
- Wing Chun 專有名詞保留羅馬拼音，例如 Chi Sau、Chum Kiu、Biu Tze。
- 技術說明使用自然英文，例如 Practical Application、Core Principles、Contact Reaction。

## 4. 網站固定文字

- 最新更新：Latest Release
- 所有課程：All Lessons
- 觀看：Watch
- 分享：Share
- AI助理：AI Assistant
- 線上聊天室：Online Chat
