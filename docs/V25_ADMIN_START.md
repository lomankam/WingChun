# V25.0 Admin Start

本版新增 `admin/index.html`，作為新增影片管理後台的第一版。

## 功能

- 貼上 YouTube 連結，擷取 Video ID
- 顯示縮圖
- 產生可加入 `data/videoIds.json` 的影片 ID
- 產生可加入 `data/wcmd.json` 的資料物件
- 英文標題可先使用 `Episode XX — English title pending`

## 安裝方式

把 `admin/` 與 `docs/` 複製到 GitHub 專案根目錄。

網址：

`https://lomankam.github.io/WingChun/admin/`
