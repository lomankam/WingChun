# V23.1 Search Engine Foundation

## 搜尋範圍

目前搜尋會比對：

- episode / 集數
- title / 中文標題
- titleEn / 英文標題
- category / 中文分類
- categoryEn / 英文分類
- level / levelEn
- keywords / keywords_en
- terminology.json 中的中文、official_en、aliases

## 設計原則

V23.1 的搜尋核心先不依賴 AI，而是建立穩定、可擴充的本地搜尋基礎。未來 AI 阿智會先使用這個搜尋核心找到相關課程，再整理回答。

## 下一步

V23.2 建議建立 Knowledge Base，讓每個核心觀念可以對應相關集數與標準說明。
